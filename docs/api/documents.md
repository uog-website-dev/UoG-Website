# Site Documents API

Documents are available at `/api/v1/sites/{site_id}/documents/`; categories use `/api/v1/sites/{site_id}/document-categories/`. All routes require the existing Keycloak authentication and Site CMS membership checks. The `DOCUMENTS` capability (and its required `MEDIA` dependency for uploaded files) must be enabled for the selected Site; a disabled module returns the standard `400` validation envelope with `reason: module_disabled`. A document identifier is always resolved inside the Site in the URL, so a foreign identifier returns `404`.

`GET` lists documents with page number pagination (`page_size` defaults to 20 and is capped at 100). Optional query parameters are `search` (title), `category` (Document Category UUID), `status`, `file_type` (`pdf` or `text`), and `visibility`. `POST` creates a draft. `GET /{uuid}/` retrieves one Site document. `GET /{uuid}/preview/` streams the verified file through a private no-store response. `PATCH /{uuid}/` updates editable metadata without replacing its identifier or publication history. `POST /{uuid}/publish/` and `/unpublish/` use the shared CMS workflow. `DELETE /{uuid}/` requires `content.documents.delete`; retained revisions are handled by the shared content deletion and audit services.

Document Categories support paginated `GET` and `POST` on `/document-categories/`, plus `GET` and `PATCH` on `/document-categories/{uuid}/`. A document editor may create or deactivate Site-owned categories through the existing Site CMS author role.

Create and update fields: `title` (required), `slug` (required), `description` (sanitized rich text), `file_reference` (`sites/{site_id}/assets/{asset_uuid}` for a ready Site PDF or text asset), `categories` (Document Category UUIDs from the same Site), `visibility` (`PUBLIC`, `UNLISTED`, `HIDDEN`), `version`, and `effective_date` (ISO date or null). Identity, Site, lifecycle, creator, revision, and timestamps are server-managed. A blank title returns a field validation error instructing the user to enter a document title.
